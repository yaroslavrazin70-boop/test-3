# Rolex Luxury Watch — GitHub Website

A responsive luxury-watch landing page built with **HTML, CSS and vanilla JavaScript**.

> **Important:** This is an unofficial front-end demo for portfolio/GitHub use. Rolex and related trademarks belong to their respective owners. No official affiliation is implied.

## Files

- `index.html` — page structure
- `style.css` — responsive design and watch illustrations
- `script.js` — mobile navigation, buttons and newsletter interaction

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose your main branch and `/ (root)`.
6. Save. GitHub will give you the live site URL.
